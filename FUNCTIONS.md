# Every AR macro function: reachable or not

From the step 0 run of 2026-10-26 on NIS-Elements 6.10.02, **on the Ti2 simulator**. "Yes" means our Python reaches the function by name through `nis.call_proc`: it was called with an argument no function can take, NIS refused the argument, and nothing ran. "No" means NIS answered *Procedure not found*: the function belongs to a module that is not installed, to hardware the simulator does not have, or to the Nk libraries, which appear once a macro loads their DLL. The same list as a spreadsheet: `functions.csv`.

**3175 of 3691 reachable.**

Reachable is not the same as callable directly. A function that hands a value back through an argument (a number, or a text with a maximum length) does not work through `nis.call_proc`: numbers fail, and a text with a maximum length corrupts NIS's memory (heap corruption), after which NIS crashes within a few calls. So `nis.call_proc` directly is not the way to go for those; see RESULTS.md.
